# Source Review Notes

This source publication is provided so Nexus Mods and other reviewers can inspect the implementation of Exiles Game Manager.

## Included

- FastAPI/Python backend
- React and TypeScript frontend source
- Nexus Mods integration implementation
- Steam Workshop integration implementation
- Authentication, permissions and storage implementation
- Tests
- Windows packaging configuration
- Dependency manifests
- Continuous-integration workflow

## Intentionally excluded

- User accounts and credentials
- API keys and access tokens
- Runtime logs and diagnostics
- Server instances, saves, backups and installed mods
- SteamCMD runtime files and Workshop cache
- Build output and generated binaries
- Internal development notes, AI-assistant files and private ticket history

The downloadable Windows installer and portable build remain available through GitHub Releases.
