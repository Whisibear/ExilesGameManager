# Security Policy

## Supported Versions

Only the latest public beta release is officially supported and receives security updates.

---

## Reporting a Vulnerability

If you discover a security vulnerability in Exiles Game Manager, please **do not** create a public GitHub issue.

Instead, please contact the maintainer privately using one of the following methods.

### Discord (Preferred)

Send a direct message to the maintainer on Discord.

**Discord Username:**

`Whisibear`

---

### GitHub

If Discord is not available, you may contact the maintainer through GitHub.

---

## Responsible Disclosure

Please allow reasonable time to investigate and resolve the issue before publicly disclosing any security-related information.

Thank you for helping keep Exiles Game Manager secure.
