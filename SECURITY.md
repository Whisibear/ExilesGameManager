# Security Policy

## Supported Versions

Only the latest public beta release is officially supported and receives security updates.

## Reporting a Vulnerability

If you discover a security vulnerability in Exiles Game Manager, please do not create a public GitHub issue.

Contact the maintainer privately through Discord or GitHub.

Discord username: `Whisibear`

## Responsible Disclosure

Please allow reasonable time to investigate and resolve the issue before publicly disclosing security-related information.
