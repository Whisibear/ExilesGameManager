# Credits and Project Lineage

Exiles Game Manager is an independently maintained fork and substantial expansion of the original ExilesGameManager / AutoPalExpress foundation.

## Project maintainers and contributors

- Original project foundation: Kvitekvist
- Exiles Game Manager project direction, architecture, interface, release workflows and ongoing maintenance: Whisibear
- SteamCMD: Valve Corporation
- UE4SS: UE4SS-RE contributors
- Palworld Save Tools: palworld-save-tools contributors
- Additional open-source dependencies: their respective maintainers and contributors

The original MIT copyright and permission notice remain in `LICENSE`. Project lineage and attribution are documented separately from current project ownership and maintenance.

## Current scope

EGM currently supports Palworld. Conan Exiles is the next planned game integration. Other games are not considered supported until their modules are implemented, documented and validated.
